
# 诉讼费批量计算工具 ⚖️

一个**纯前端、完全离线可用**的诉讼费用计算工具。支持批量输入多个标的金额，一键计算对应的**案件受理费、保全费、执行费**，并将结果导出为 Excel 表格下载到本地。

无需安装、无需服务器、不上传任何数据，打开网页即可使用。

> 🚀 **在线使用**：[https://courtfee.github.io/](https://courtfee.github.io/)

---

## ✨ 功能特性

- 📋 **批量计算**：一次性输入任意多个金额，逐行批量计算
- 🧾 **三种输入方式**：
  - 文本框直接粘贴，按换行区分
  - 导入 `xlsx` 文件（读取第一列金额）
  - 导入 `xls` / `csv` / `txt` / `tsv` 等文本表格文件
- 📊 **一键导出**：计算结果导出为 Excel 可直接打开的 `.xls` 表格
- 🔒 **数据安全**：所有计算均在浏览器本地完成，不联网、不上传、不留痕
- 📴 **完全离线**：单个 HTML 文件即全部程序，下载后双击即可离线使用
- 💻 **零依赖**：不依赖任何外部 JS 库或网络资源（xlsx 解析为内置原生实现）

## 📖 使用方法

### 1️⃣ 批量输入金额

在文本框中粘贴金额，**每行一个**，支持多种写法：

```
1000
50,000
￥200000
1000000
1,000,000
```

- 自动去除千分位逗号（`,` 或 `，`）、人民币符号（`￥`）和空格
- 每行取**第一个数字**作为金额
- 无效行自动忽略，不中断计算

### 2️⃣ 导入表格文件

点击 **「导入 xlsx / xls / csv / txt」** 按钮：

- ✅ `.xlsx`：读取**第一个工作表第一列**中的金额
- ✅ `.xls`（HTML 表格格式）/ `.csv` / `.txt` / `.tsv`：读取第一列金额
- ⚠️ 老式二进制 `.xls`（Excel 5.0/97-2003 真实二进制格式）暂不支持，请先在 Excel 中另存为 `xlsx` 或 `csv`

### 3️⃣ 计算并导出

1. 点击 **「计算」** 按钮，结果即时显示在表格中
2. 点击 **「导出 Excel .xls」** 按钮，下载结果表格

**导出表格格式示例：**

| 序号 | 输入金额 | 计算受理费用 | 计算保全费用 | 计算执行费用 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | 1000 | 50 | 30 | 50 |
| 2 | 50000 | 1050 | 520 | 650 |
| 3 | 200000 | 4300 | 1000 | 4400 |
| 4 | 1000000 | 13800 | 3020 | 12400 |

导出的 `.xls` 文件可直接用 Microsoft Excel、WPS、LibreOffice 打开并另存为 `.xlsx`。

## 🚀 部署到 GitHub Pages

### 方式一：新建仓库（推荐）

1. **Fork 或新建仓库**，上传以下文件：

```
├── index.html        # 工具主文件（即前述 HTML，可重命名为 index.html）
├── README.md         # 本说明文件
└── LICENSE           # 开源协议（可选）
```

2. **开启 GitHub Pages**：
   - 进入仓库 **Settings → Pages**
   - **Source** 选择 `Deploy from a branch`
   - **Branch** 选择 `main`（或 `master`），目录选 `/ (root)`
   - 点击 **Save**

### 方式二：本地离线使用

直接下载 `诉讼费批量计算工具.html`，**双击用浏览器打开**即可，全部功能离线可用，无需任何部署。
